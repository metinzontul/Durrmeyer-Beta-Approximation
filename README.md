**A robust, non-parametric regression estimator and approximation framework based on the Durrmeyer-Beta operator.**

This repository contains the official Python implementation and reproducible benchmarking suite for the Durrmeyer-Beta operator. The project bridges pure approximation theory with applied machine learning by deploying a variation-diminishing mathematical operator as a parameter-free regression estimator. It demonstrates superior structural integrity and outperformance against traditional time-series models (ARIMA), classical non-parametric approaches (Gaussian Kernel Smoother), and modern deep learning architectures (LSTM Autoencoders) under extreme industrial noise.

## 🚀 Key Features

*   **Non-Parametric Robustness:** Reconstructs underlying continuous manifolds from heavily noisy data without hyperparameter tuning, backpropagation, or weight optimization.
*   **Extreme Noise Tolerance:** Maintains topological integrity and high $R^2$ scores even when the signal-to-noise ratio collapses (tested up to Std = 16.0).
*   **Statistical Rigor:** All machine learning benchmarks are computed over 30 independent noise realizations to provide transparent variance estimates (Mean $\pm$ Std).
*   **Numerical Stability:** Resolves standard underflow issues in infinite summation operators via a dynamic outer series truncation methodology (omitted mass $< 10^{-14}$) and highly calibrated adaptive quadrature.
*   **Wider Interval Support:** Includes extended tests on $[0, 20]$ for functions with discontinuous higher-order derivatives, ensuring boundary stability.
*   **Bivariate Extension:** Provides full tensor-product implementations for 3D surface approximations of both smooth and non-smooth functions over $[0, 2]^2$.

## 🧮 Mathematical Formulation

The proposed univariate Durrmeyer-type operator utilizes Lupaş-Agratini weights and a normalized beta-prime integral kernel:

$$D_n(f; z) = \sum_{k=0}^{\infty} p_{n,k}(z) \int_0^\infty q_{n,k}(t) f(t) dt$$

where the outer weights follow a negative binomial distribution:
$$p_{n,k}(z) = \binom{nz+k-1}{k} \frac{1}{2^{nz+k}}$$

To compute the Beta-prime expectation on bounded domains without numerical overflow, the algorithm applies the transformation $x = \frac{t}{1+t}$, mapping the inner integral to the standard Beta distribution over $(0,1)$.

## 📁 Repository Structure & Python Scripts

The codebase is strictly organized into performance benchmarking (signal processing) and theoretical approximation evaluations.

### 📊 1. Benchmarking & Machine Learning (Author: Metin Zontul)
These scripts evaluate the operator's capabilities as a non-parametric regression tool under extreme Gaussian noise.
*   `dbsl_extended_benchmark.py`: The core evaluation engine. Executes a parallelized comparative robustness analysis evaluating the Durrmeyer-Beta operator against an ARIMA(2,0,2) model, an LSTM Autoencoder, and a Gaussian Kernel Smoother. Outputs metrics across 30 independent noise realizations.
*   `ablation logs.txt`: The raw text output containing Mean $\pm$ Standard Deviation metrics (NRMSE, NMAE, $R^2$) generated by the extended benchmark.
*   `generate_ablation_figures.py`: Visualization module. Parses `ablation logs.txt` directly to ensure 100% data transparency and reproducibility. Generates high-resolution (600 DPI) plots illustrating error degradation (`Figure_8_NRMSE.png`, `Figure_9_NMAE.png`) and structural integrity (`Figure_10_R2.png`).

### 📐 2. Approximation Theory & Boundary Testing (Author: Seda Karateke)
These scripts handle the theoretical validation, error distribution, wide-interval boundaries, and tensor-product extensions of the operator.
*   `generate_univariate_figures.py`: Evaluates the univariate operator on bounded continuous test functions over $[0, 2]$, generating approximation curves and absolute error distribution plots.
*   `bounded_wide_example.py`: Specifically tests the operator's capabilities on a significantly wider domain ($[0, 20]$) using a continuous function with a discontinuous second derivative (S-Curve). Includes independent tail error calculations and generates `figure_wider_interval_bounded.png`.
*   `bounded_wide_results.npz`: A compressed NumPy archive containing the raw target points, predictions, and numerical grids generated by `bounded_wide_example.py` for instant redrawing without recalculating integrals.
*   `generate_bivariate_approximation_figures.py`: Evaluates the tensor-product Durrmeyer-Beta operator for 3D surfaces. Generates colormapped 3D projections and absolute error heatmaps for both smooth and non-smooth targets.
*   `calculate_bivariate_metrics.py`: Computes theoretical bivariate approximation accuracy metrics (RMSE, MAE, R², $E_\infty$) for structured manuscript tables.
